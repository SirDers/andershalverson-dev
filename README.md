# Anders Halverson's Portfolio Website

This repository contains the source code for my personal portfolio website, which showcases my work as a **Software Engineer, Producer, and Game Designer**.

## Why I Made This Website

I created this website to serve as a central hub for my professional identity and creative projects. As a Computer Science student at the University of Wisconsin-Stout with a concentration in Game Design, I wanted a platform that could:

- **Showcase My Projects:** From my early work in Construct 3 like *Quick Whips* and *Breath of the Galaxies*, to more recent university projects like *Super Short Bros.* (JavaFX) and *Justice is Blind* (Unity/C#), and my ongoing work on *Stella Game Engine* (C++/OpenGL) and *Frost-X Rex* (Unreal Engine/C++).
- **Highlight My Unique Background:** I’ve lived in Tanzania, studied in Ireland, and have a passion for cross-cultural understanding, which I believe enhances my creative input and leadership in game design.
- **Provide Easy Access to My Resume:** A dedicated section for recruiters and collaborators to view and download my current resume.
- **Serve as a Contact Point:** To make it easy for anyone to reach out via email, LinkedIn, or GitHub.

## Website Features

- **Home:** A dynamic landing page with a background video and an introduction to my core roles.
- **About:** A section detailing my educational background, personal history, and design philosophy.
- **Projects:** A chronological timeline of my game development journey, detailing the technologies used and lessons learned.
- **Resume:** An embedded PDF viewer for my professional resume.
- **Contact:** Links to my professional profiles and direct contact information.

## Technologies Used

- **HTML5:** Semantic structure for the website content.
- **CSS3:** Custom styling with animations (fade-in/fade-up), responsive design, and a clean, modern aesthetic.
- **JavaScript:** Used for scroll-triggered header transitions and intersection observers for smooth entrance animations.
